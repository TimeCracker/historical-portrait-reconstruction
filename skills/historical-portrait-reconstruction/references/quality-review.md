# Review the final board

## Individual fidelity

Inspect the board and the original file. Record observations, not a fabricated
similarity percentage.

| Check | Pass condition |
| --- | --- |
| Identity | The displayed source belongs to the named person and chosen work; disputed identification is labelled |
| Authentic left panel | It is the recorded source file's crop with proportional scaling; no AI redraw, face replacement or beautification |
| Face outline | Width/height, cheeks, jaw and chin follow what is visible in the source |
| Features | Brow direction, lids, eye spacing, nose, mouth and beard growth are not replaced by a generic template |
| Pose | Source pose is preserved unless an explicitly requested alternative is labelled inference |
| Uncertainty | Obscured features, texture and depth are distinguished from source evidence |
| Colour and dress | Paint ageing is not treated as certain skin colour; costume fidelity is reviewed separately |
| Presentation | Both panels are large enough to inspect; labels and source note are readable and outside image content |
| Provenance | Input hashes, crop, resizing and output can be traced to the specific files |

Review after composition, because a correct generation can still be paired
with the wrong original or cropped misleadingly.

## Across people

Compare face outlines, eyelids, nose proportions, cheeks, chin and beard
attachment while ignoring hat and robe differences. Repeated geometry is a
reason to recheck each person's reference and contract, not proof the historical
people looked different.

Repair a failed identity from that person's original reference. Do not create
distinction through invented scars, skin colour, age or bone structure.
If a common source tradition limits distinguishability, record the limitation.

## Completion

Keep the expected distinct IDs from the request. For each ID record:
source selected, reference inspected, generation completed, board composed,
board visually reviewed, selected final output, and blocker if any.

A successful script batch establishes composition status only. Do not mark
generation or visual review complete merely because a file exists.
If a tool genuinely limits a call, continue in later calls. Do not invent a
global ten-image cap or leave completed originals out of final delivery.

A source cannot validate true historical likeness. A generated right panel
cannot validate the source's attribution.
