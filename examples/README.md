# Examples

- [Qin Shi Huang](qin-shi-huang/README.md): one later painting, an explicit crop, and an individual generation prompt.
- [Sixteen Ming emperors](ming-portraits/README.md): person-specific records and prompts plus a 16-item composition manifest.

These examples publish records and prompts only. Source scans, generated portraits, and comparison images are not bundled. Obtain and review the sources, generate portraits with actual reference-image input, then run the compositor. A prompt that requests a single portrait describes the **generation stage**; final delivery still requires the authentic source and generated interpretation together.

Byte hashes identify the exact source files used in the earlier workflow. They do not certify the depicted person’s historical likeness or the file’s reuse rights.
